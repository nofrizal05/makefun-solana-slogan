A one-line slogan for a Solana wallet agent, written by a small Python program (standard library only) for make.fun's "One-Line Slogan for a Solana Wallet Agent" bounty. The program writes exactly one slogan to `/output/entry.txt`:

> Solana at the speed of thought: your wallet agent swaps, sends, and signs before you've finished the sentence.

## Run it

```sh
python3 main.py
```
